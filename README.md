# AI Assistant on Streamlit

Мой первый веб-проект на Python и Streamlit.

## Возможности

- веб-интерфейс на Streamlit
- AI-чат
- история сообщений
- подключение OpenAI API
- публикация через Streamlit Community Cloud

## Запуск

```bash
streamlit run app.py
```

## Технологии

- Python
- Streamlit
- OpenAI API
- GitHub
- Streamlit Community Cloud
